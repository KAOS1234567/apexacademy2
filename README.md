# Apex Football Academy — أكاديمية أبيكس لكرة القدم

الموقع الرسمي لأكاديمية أبيكس لكرة القدم. موقع ثابت (Static Website) يقدّم
الهيكل الأساسي للأكاديمية: الصفحة الرئيسية، صفحة التعريف بالأكاديمية،
وصفحة برامج التدريب.

## الصفحات

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة الرئيسية — القسم الترحيبي، المميزات، الإحصائيات، ونظرة على البرامج. |
| `about.html` | عن الأكاديمية — القصة، الرسالة، الرؤية، القيم، وفريق المدربين. |
| `training.html` | التدريبات — الفئات العمرية، الجدول الأسبوعي، الاشتراكات، ونموذج التسجيل. |

## البنية

```
apexacademy2/
├── index.html          # الصفحة الرئيسية
├── about.html          # عن الأكاديمية
├── training.html       # التدريبات
├── css/
│   └── style.css       # ملف التنسيق الأساسي (Design System)
├── js/
│   └── main.js         # قائمة التنقل للأجهزة المحمولة + سنة الحقوق
└── assets/
    └── pitch.svg       # خلفية الملعب للقسم الترحيبي
```

## المميزات التقنية

- تصميم متجاوب (Responsive) يعمل على الجوال والحاسوب.
- دعم كامل للاتجاه من اليمين إلى اليسار (RTL) واللغة العربية.
- نظام تنسيق موحّد عبر متغيرات CSS (ألوان، خطوط، مسافات، ظلال).
- قائمة تنقّل قابلة للطي على الشاشات الصغيرة عبر JavaScript خالٍ من المكتبات.
- بدون أي اعتماديات خارجية — HTML و CSS و JavaScript صرف.

## التشغيل محلياً

الموقع ثابت بالكامل، لذا يكفي فتح `index.html` في المتصفح، أو تشغيل خادم محلي:

```bash
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```
