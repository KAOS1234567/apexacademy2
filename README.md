# apexacademy2

نظام إدارة أكاديمية كرة القدم — **أكاديمية أبيكس** (Apex Football Academy).

هذا المستودع يحتوي على الهيكل الأساسي للموقع التعريفي للأكاديمية، مبنيّ بلغات
الويب القياسية (HTML5 و CSS3 و JavaScript بسيط) بدون أي اعتماديات خارجية،
وبتصميم عربي متجاوب من اليمين إلى اليسار (RTL).

## الصفحات

| الصفحة | الملف | الوصف |
| --- | --- | --- |
| الصفحة الرئيسية | `index.html` | واجهة العرض الأولى مع المميزات والإحصائيات ولمحة عن البرامج. |
| حول الأكاديمية | `about.html` | القصة والرؤية والرسالة والقيم والطاقم التدريبي. |
| التدريبات | `training.html` | برامج الفئات العمرية والجدول الأسبوعي والإرشادات. |

## البنية

```
apexacademy2/
├── index.html          # الصفحة الرئيسية
├── about.html          # صفحة حول الأكاديمية
├── training.html       # صفحة التدريبات
├── css/
│   └── style.css       # ملف التنسيق الأساسي (متغيرات، مكوّنات، استجابة)
├── js/
│   └── main.js         # قائمة التنقل للجوال + سنة حقوق النشر التلقائية
└── README.md
```

## التشغيل محلياً

الموقع ثابت (Static) بالكامل، لذا يكفي فتح `index.html` مباشرةً في المتصفح.
أو تشغيل خادم محلي بسيط:

```bash
# باستخدام Python
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## ملاحظات

- التصميم يعتمد على متغيّرات CSS (Design Tokens) لسهولة تغيير الألوان والمقاسات.
- التخطيط متجاوب ويدعم الأجهزة المحمولة عبر قائمة تنقّل قابلة للطي.
- بيانات التواصل والأرقام هي بيانات تجريبية (Placeholder) يمكن تحديثها لاحقاً.
